# Tomato Focus

一个白色毛玻璃风格的番茄钟界面原型，使用原生 HTML、CSS 和 JavaScript 实现，无需安装依赖。

## 使用

直接在浏览器中打开 `index.html`。

## 功能

- 专注、短休、长休三种计时模式
- 开始、暂停、重置、跳过
- 中央毛玻璃主面板和沉浸专注模式
- 自定义专注/休息时长、长休间隔、今日目标
- 自动开始下一轮设置
- 今日完成数、专注分钟、连续轮数、完成任务统计
- 任务队列、当前任务选择、任务番茄记录、完成/清理任务
- 历史专注记录，按日期查看最近完成的专注
- Electron 桌面版支持“置顶小窗”，双击小窗或按 `Esc` 可恢复完整窗口
- 桌面通知和提示音
- 专注备注
- 键盘操作：空格开始/暂停，`R` 重置，`S` 跳过
- 本地持久化保存设置、任务、统计和历史记录

## 后续桌面化

如果要打包成真正的桌面应用，推荐接入 Tauri 2，并把当前页面作为前端入口。
